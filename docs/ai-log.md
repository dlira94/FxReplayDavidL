| Sep 18 | Claude Code | **Accepted with correction** | Build masked text entrances driven by IntersectionObserver | **The bug that produced no error.** Twenty-two elements rendered invisible and stayed that way: no build error, no type error, no failing test, no console output. It said so rather than quietly moving on, and went looking again.<br><br>**How it was isolated:** a side-by-side control in the live page — two sibling elements, one observer, identical options, identical scroll position, `clip-path` removed from one. One measurement, no ambiguity left.<br><br>**Fix:** `mask-image` instead, which is a paint effect and leaves the layout box alone — same wipe, no deadlock.
